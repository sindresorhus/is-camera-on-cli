# is-camera-on-cli

> Check if a Mac camera is on

## Install

```sh
npm install --global is-camera-on-cli
```

Requires macOS 10.15 or later.

## Usage

```
$ is-camera-on --help

  Example
    $ is-camera-on
    ✔ Camera is on

  Exits with code 0 if on and 1 if off
```
